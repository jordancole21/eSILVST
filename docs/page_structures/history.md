# History

- **Header Block**: A fixed header with the eSILVST Wallet logo on the left and a back arrow icon labeled "Back to Dashboard" on the right.
- **Filter Block**: A top filter bar with dropdowns for "Type" (All, Buy, Sell) and "Date Range" (All Time, Last 7 Days, Last 30 Days), with a small "Apply" button to update the list.
- **Transaction List Block**: A scrollable list of transaction cards below the filter, each card showing a transaction summary with date (e.g., "4/9/2025"), type (e.g., "Bought 2.5 eSILVST"), and value (e.g., "for 0.023 ETH"), with a small "View on Etherscan" link for blockchain verification.
- **Quick Action Block**: A centered "Trade Now" button in a contrasting color at the bottom of the list, visible after scrolling, to encourage new transactions.
- **Navigation Bar Block**: A fixed bottom navigation bar with icons and labels for "Dashboard", "Trade", "Market", "History" (highlighted), and "Settings".
