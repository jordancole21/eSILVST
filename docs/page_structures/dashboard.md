# Dashboard (Main User Interface)

- **Header Block**: A fixed header with the eSILVST Wallet logo on the left and a user avatar or wallet address snippet (e.g., "0x...1234") on the right, tappable for quick logout or settings access.
- **Balance Overview Block**: A prominent card at the top showing "eSILVST Balance: X.XX tokens (X.XX oz of Silver)" and "ETH Balance: X.XX ETH" in large text, with a small "Refresh" icon button to update values.
- **Reserve Ratio Block**: Below the balance card, a small status indicator stating "Reserve Ratio: X.XX (XXX% Backed)" with an info icon for a tooltip explaining the ratio.
- **Quick Action Block**: A set of two primary action buttons below the metrics, labeled "Buy eSILVST" and "Sell eSILVST", displayed prominently in contrasting colors for immediate trading access.
- **Navigation Bar Block**: A fixed bottom navigation bar with icons and labels for "Dashboard" (highlighted), "Trade", "Market", "History", and "Settings", designed for thumb-friendly access on mobile.
